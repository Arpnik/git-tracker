# Instructions for AI assistants

## Hard rules

- **Never disclose commit messages from professional / industry work.** Any repo
  owned by an org under `professional_orgs` in `config/profile.yaml` (or listed in
  `professional_repos`) is industry work. Its commit messages must never appear in
  `README.md`, `README_STATS.md`, `index.html`, `data/stats.json`, SVGs, commit
  messages, PR descriptions, logs you print, or anything else that gets published.
  Only aggregate numbers (commits, lines, areas, languages) may be shown.
  Code enforces this in `scrub_messages` (`scripts/dev_tags.py`) and in
  `aggregate.build`. Do not add an option that turns it off.
- Don't link private repos (readers would hit a 404).

## How the profile is built

`README.md`, `README_STATS.md`, `index.html` and `assets/*.svg` are generated by
`scripts/render.py` from `data/stats.json` + `config/profile.yaml`. Don't edit them
by hand; change the config or the renderer, then run `python scripts/render.py`.
